Quick Setup:

  • Classic Token: Generate with repo and read:user scopes. 👉 Click to Generate with Pre-filled Scopes
  • Fine-Grained Token: Under Repository Permissions, select Contents: Read and write, Pull requests: Read and write, and Metadata: Read-only.

Token is kept in browser memory and transmitted only to GitHub. It is never logged or written to disk.
